WhatsApp

Use a API oficial do WhatsApp Business (Meta Cloud API).

Passo a passo
  1. Em developers.facebook.com, crie um app do tipo "Empresa" e adicione o produto WhatsApp.
  2. Copie o ID do número de telefone e gere um token de acesso permanente (usuário do sistema no Gerenciador de Negócios).
  3. Em WhatsApp → Configuração → Webhook, cole a URL e o token de verificação abaixo e assine o campo messages.
